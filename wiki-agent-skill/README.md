# Wikipedia Analytics Skill for B2C Market Research

Інструмент для автоматичного збору даних переглядів статей у Вікіпедії, аналізу трендів та генерації аналітичного PDF-звіту.

## Структура проєкту
- `SKILL.md` — інструкція та специфікація навички для ШІ-агента.
- `main.py` — основний скрипт для збору даних, побудови графіків та генерації PDF.
- `report.pdf` — приклад автоматично згенерованого аналітичного звіту.
