# Wikipedia Market Analytics Skill

Ця навичка дозволяє AI-агенту аналізувати динаміку попиту на різні теми у різних мовних розділах Вікіпедії, проводити порівняльний аналіз, виявляти тренди та формувати PDF-звіт з бізнес-рекомендаціями.

## 1. Коли використовувати навичку
Застосовуй цю навичку, коли користувач ставить запитання щодо:
- Порівняння інтересу до теми між різними країнами/мовами (наприклад, Польща vs Чехія).
- Оцінки доцільності додавання нового курсу або фічі у B2C-застосунок (наприклад, курс з астрономії чи вивчення мов).
- Перевірки надійності та стійкості тренду (чи це тимчасовий сплеск, чи стабільне зростання).

## 2. Як виконувати аналіз (CLI Interface)
Запускай скрипт `main.py`, передаючи назви статей та мовні коди через параметр `--topics`:

```bash
python main.py --topics "<Назва_1>:<мова_1>" "<Назва_2>:<мова_2>"
python main.py --topics "Głodówka:pl" "Přerušovaný půst:cs"
python main.py --topics "Астрономія:uk"
python main.py --topics "Język angielski:pl" "Angličtina:cs" "Англійська мова:uk"
```
## 3. Правила інтерпретації та висновків
1. **Оцінка тренду (за останні 6 місяців):**
   - **Зростання > +10%:** Позитивний сигнал. Високий потенціал для запуску продукту чи курсу.
   - **Флет (від -10% до +10%):** Стабільний осередковий попит.
   - **Падіння < -10%:** Негативний сигнал. Запуск курсу недоцільний через спад зацікавленості ринку.
2. **Оцінка обсягу аудиторії:**
   - Низькі абсолютні перегляди (< 500/міс) вказують на вузьку нішу та високий ризик недобору клієнтів.
3. **Перевірка надійності даних (Довіра до тренду):**
   - Перевіряй наявність аномальних сплесків. Якщо зростання відбулося за 1 місяць, а потім впало — це новинний хайп, якому **не можна довіряти** для довгострокових інвестицій.

## 4. Обмеження даних (Data Limitations)
- **Інформаційний запит ≠ Купівельна спроможність:** Перегляди статей у Вікіпедії вимірюють інтерес, але не гарантують готовність купувати платний продукт.
